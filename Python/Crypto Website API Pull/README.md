## Automating Crypto Website API Pull

Here you'll find my ccode for an Automating Crpyto Website API Pull project, we used CoinMarketCap's API to retrieve realtime data on Crypto and created visualisations that showcased the ups and downs of Bitcoin over a span of 5 minutes however this project could be ran for longer, adjusted to multiple Cryptos etc. 

## Tools/Skills Used
• Python

• Pandas

• Matplotlib.pyplot & Seaborn 

## Project Goal
Using Python pull from CoinMarketCap's API to retrieve realtime data on Crypto and produce a visualisation showcasing the trend of "Bitcoin".
